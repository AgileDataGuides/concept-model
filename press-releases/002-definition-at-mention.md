# @Mention Linking in Concept Definitions

**FOR IMMEDIATE RELEASE**
**Date: 2026-03-28**

## Link glossary terms directly inside concept definitions with @mention tagging

**Wellington, New Zealand** — The Concept Model app now supports @mention tagging in the definition differentiator field. When writing what distinguishes a concept, type `@` followed by a term name to see a dropdown of matching glossary terms. Select one, and it is stored as `@{TermName}` and rendered as an orange pill on the canvas.

### How It Works

In the concept edit modal, the "that..." differentiator field now supports @mention:

1. Type `@` followed by a few characters (e.g. `@cust`)
2. A dropdown appears with matching glossary terms
3. Use arrow keys or click to select
4. The term inserts as `@{Customer}` and renders as an interactive orange pill

### Typeahead for Definition Category

The "is a..." category field also provides typeahead suggestions. Start typing and existing concepts are offered as autocomplete options, making it easy to build a consistent taxonomy hierarchy.

### Consistent Across All Canvases

The @mention pattern is shared across all canvases that support Aristotelian definitions: Concept Model, Business Glossary, and Business Event Matrix. The storage format (`@{TermName}`) and rendering (orange pills) are identical everywhere.
