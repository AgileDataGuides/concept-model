# The Concept Model's Definitions Tab Now Jumps to Any Concept and Finds It by Name

**9 October 2026**

AgileDataGuides today released a rail and a search for the Concept Model's Definitions tab, so a reader can go straight to the Definition they need instead of scrolling for it.

## The Problem

The Definitions tab reads the whole Concept Model as one long document: every Concept's Definition by Domain, then every Relationship, then every Core Business Event. That is the right shape for reading it through. It is the wrong shape for a question in a workshop. When someone asks "what did we agree a Warehouse is?", the facilitator had to scroll down past every card above it, reading names as they went by. The Blue Book's worked example has 13 Concepts. A real Model has many more, and the scroll got longer each week.

## The Solution

The Definitions tab now has the same two columns as the Steps tab. A rail down the left lists Scope, every Concept under its Domain with its Definition status, then the Relationships and the Core Business Events. Click a Concept and the document jumps to its card and outlines it. Scroll by hand and the rail marks the card you are reading. A search at the top of the rail finds a Concept by name: type a few letters, press Enter, and you are there.

## How It Works

The document itself never changes. The search narrows only the rail, to the Concepts whose name holds the letters typed, so the Definitions still read top to bottom for anyone following along on a shared screen. Escape clears the search. The rail and the search are view choices: they never mark the Model as changed.

## Key Benefits

- **Any Definition in one click.** The question "what did we agree an X is?" is answered in a second, not a scroll.
- **Find a Concept by name.** A few letters and Enter jump to it, however long the Model grows.
- **One way to move round the app.** The Definitions tab moves like the Steps tab, so there is nothing new to learn.
- **Status at a glance.** Each Concept's Draft, Agreed or Flagged chip sits in the rail, so the unfinished Definitions stand out before anyone scrolls.

The Definitions rail and search are available now in the Concept Model app in the Context Plane monorepo.
