# Search Filtering Across All Canvas Sections

**FOR IMMEDIATE RELEASE**
**Date: 2026-03-28**

## Quickly find items in any canvas list with progressive-disclosure search

**Wellington, New Zealand** — The Concept Model canvas now includes search filtering on all four entity lists: Concepts, Core Business Events, Core Business Processes, and Domains. Type to instantly filter items by name.

### Progressive Disclosure

Search inputs appear automatically when a section contains 5 or more items. Smaller lists remain uncluttered. This threshold-based approach keeps the canvas clean for new models while scaling gracefully as models grow.

### Consistent Design Pattern

Each search input features a magnifying glass icon, placeholder text, and a clear button (x) that appears when a query is active. The pattern is consistent across all canvas apps in the monorepo — Concept Model, Business Glossary, Data Dictionary, and Information Product Canvas all use the same search UX.

### Instant Filtering

Filtering is instantaneous — no debounce, no submit button. As you type, the list narrows to matching items. Clear the search to restore the full sorted list. Drag-and-drop reordering continues to work on filtered results.
